# 🤖 Genius - Assistente IA

Projeto de assistente virtual inteligente desenvolvido em Python usando a API do Google Gemini e o framework Streamlit.

## Como Executar
1. Crie o ambiente virtual: `python -m venv venv`
2. Ative o ambiente virtual:
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
3. Instale as dependências: `pip install -r requirements.txt`
4. Adicione sua chave no arquivo `.env`.
5. Execute a aplicação: `streamlit run app.py`
